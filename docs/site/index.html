Real Vista documentation

A multi-tenant CRM for real estate agencies: leads, property owners, listings, deals and paperwork in one workspace, with share links an agency controls.

What it is

Real Vista is a SaaS CRM for real estate agencies. One deployment serves many agencies; each agency gets an isolated workspace with its own users, properties, leads, branding and pipeline. Agency staff (admins and employees) work in the CRM; sellers use a lighter surface; people outside the agency see only what is deliberately shared with them through expiring links.

Principles you will meet everywhere

PrincipleIn practice
Isolation is enforced in the data layerA global Mongoose plugin scopes every query to one workspace. A query with no tenant context throws rather than returning someone else's records. Details
Vocabulary in code, selection in configPermissions, notification types, webhook events, rules, pipeline stages and screens are fixed catalogues in one file each; a workspace chooses from them and never supplies code.
The property book is privateNothing about a listing is reachable without a session. Sharing goes through expiring, revocable links. Sharing
One error shapeEvery failure is { success:false, statusCode, code, message, requestId }. Branch on code. Pipeline
Claims match codePublic pages carry no invented statistics, and policy text changes with the behaviour it describes.

Keeping these docs true

  • The API reference is generated: npm run docs:openapi rewrites docs/openapi.json from the live router, then npm run docs:site rebuilds this site into docs/site.
  • Pages are fragments in docs/site-src/pages. The build fails on a navigation entry with no page and on a broken internal link.
  • When a change alters behaviour a page describes, change the page in the same commit.
