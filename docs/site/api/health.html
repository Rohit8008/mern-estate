health

API reference › health. 6 endpoints under /api/health.

Endpoints

GET/api/health/healthPublic

Load-balancer probe; no request context to authenticate.

GET/api/health/readyPublic

Readiness probe for the orchestrator.

GET/api/health/livePublic

Liveness probe for the orchestrator.

GET/api/health/startupPublic

Startup probe for the orchestrator.

GET/api/health/detailedPublic

Dependency status for on-call. Reports up/down only — no data, no configuration values.

GET/api/health/metricsPublic

Scrape endpoint for the metrics collector; bearer METRICS_TOKEN when set.
