unsubscribe

API reference › unsubscribe. 2 endpoints under /api/unsubscribe.

Endpoints

GET/api/unsubscribe/{token}Public

The unsubscribe link in an automated email, opened by a lead with no account. The signed token names one lead and is the whole credential; the response is the agency name and a masked address only. Rate limited.

Parameters

NameInTypeRequired
tokenpathstringyes

POST/api/unsubscribe/{token}Public

Records the unsubscribe — from the page, or from a mail client's one-click button (RFC 8058), which sends no cookies or CSRF header. It can only stop email to the address on the lead the signed token names. Rate limited.

Parameters

NameInTypeRequired
tokenpathstringyes
