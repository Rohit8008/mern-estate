auth

API reference › auth. 9 endpoints under /api/auth.

Endpoints

POST/api/auth/signupPublic

Self-registration. Rate limited.

POST/api/auth/signinPublic

The sign-in endpoint itself. Rate limited.

Body (JSON)

FieldTypeRequiredNotes
emailstringyesemail
passwordstringyes

POST/api/auth/refreshPublic

Exchanges a refresh cookie; the cookie is the credential.

GET/api/auth/csrfPublic

Echoes the caller its own CSRF cookie value. Carries no authority and reveals nothing a same-origin script could not already read; cross-origin callers cannot read the response.

GET/api/auth/invite/{token}Public

An invited user has no session and cannot know their workspace — the token supplies it. Returns only the workspace name/logo and the address it was sent to; unknown, expired and used tokens all answer the same way. Rate limited.

Parameters

NameInTypeRequired
tokenpathstringyes

POST/api/auth/invite/{token}Public

Completes account setup. The 32-byte token IS the credential, stored hashed, single-use and expiring. Rate limited.

Parameters

NameInTypeRequired
tokenpathstringyes

POST/api/auth/signoutSession

Sends X-CSRF-Token (from GET /api/auth/csrf) because it changes data.

POST/api/auth/signout-allSession

Sends X-CSRF-Token (from GET /api/auth/csrf) because it changes data.

GET/api/auth/clear-rate-limitPublic

Only mounted when NODE_ENV=development — see routes/auth.route.js. Never exists in production, which the route-access test confirms by not finding it.
