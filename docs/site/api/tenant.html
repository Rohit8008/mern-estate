The sign-in screen needs this workspace's name, logo and colours before anyone has signed in. Serves toPublicConfig() only — never limits, billing or internal notes.

GET/api/tenant/lookupPublic

The sign-in Workspace field confirms the name typed exists and shows what it is called. Returns slug, name and logo only; rate limited like sign-in.
