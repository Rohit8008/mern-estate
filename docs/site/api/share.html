share

API reference › share. 4 endpoints under /api/share.

Endpoints

GET/api/share/open/{token}Public

A share link an agent sent to a buyer. The 32-byte token IS the credential; links expire, can be revoked and can carry a passcode. The response is an explicit allowlist of fields — never owner contacts, internal notes, assignment or commission. Rate limited.

Parameters

NameInTypeRequired
tokenpathstringyes
